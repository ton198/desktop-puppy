# Snoopy 素材整理（2026-10-01）

这是素材审查目录，不是已集成的动画资源系统。没有修改 C# / WPF 功能代码。

- `sources/`：8 张原始上传图，不做覆盖修改；manifest 记录原文件名、SHA-256 及入选状态。另一只手打招呼、高位近似图保留为备用。
- `frames/`：统一 1254×1254 RGBA；`idle` 为母版，`blink-half`、`blink-closed`、`happy` 只替换眼部；`greeting-low/high-aligned` 为分段位置对齐图；`greeting-low/high` 为保留母版头部及脚部的局部合成候选。
- `previews/index.html`：离线预览、母版叠图和整体位置微调。直接用浏览器打开即可。交互参数仅用于比较，不保存或覆盖图。
- `alignment.json`：原图坐标下的参考点、手臂帧校准点、水平比例、微调偏移、时长。单位都是 1254 像素原图单位，不是桌面显示单位。
- `tools/build_review_assets.py`：从本目录已存档原图重建 PNG / GIF / 检查报告，不再依赖 Temp。

## 已执行的定位处理

母版：头顶 y113、项圈参考中心 (630,619)、脚底 y1130。基于 alpha>128 的可见轮廓和红项圈测量，人工取整作为对齐参考点。

高位原图：头顶 y117、项圈 (637,629)、脚底 y1147。项圈需左移约7、上移约10，脚底需上移约17。不能用一个整图平移同时满足三个点，因此分别对头部和项圈以下进行纵向缩放，水平以项圈为锚点缩放到98%。这只是几何对齐，不保证轮廓一致。

低位图只需极小的纵向校准。局部合成进一步固定不参与动作的部位：眨眼眼部矩形 (510,270)-(685,380)，边缘向内8px羽化；手臂帧替换上身区 (435,650)-(875,840)，高位额外替换手掌区 (700,580)-(855,660)，向内6px羽化。蒙版之外严格保留母版像素。

所有预览均采用同一个裁切 (280,90)-(980,1150)，不单独裁切每帧。PNG 保留透明；GIF 为带背景检查图，不能当作透明运行资源。

## 重建

在项目根目录执行（依赖 Pillow、numpy；预览标签字体使用 Windows Arial）：

```powershell
& 'C:\Program Files\Python311\python.exe' 'assets\snoopy\tools\build_review_assets.py'
```

脚本校验原图哈希、尺寸、眨眼蒙版外像素、手臂帧头部及脚部像素、GIF帧数和时长。`previews/verification.json` 保存结果。

## 尚需审查

1. 肩膀至固定身体的连接处是否自然；臀部、尾巴与腿根已固定，不能据此保证所有上身过渡都流畅。
2. 低位到高位同时包含前臂旋转，仅三种姿势可能显得偏跳。先测试节奏，不急于继续生成。
3. 闭眼线条的位置目前保留上传版本；如果自然眨眼仍显得位置偏高，后续只调整眼部，不挪整个人物。
4. 半闭眼作为60ms过渡，不宜作为长时间待机表情。高位停留450ms为第一版试用时长。
5. 还没有程序内实际播放、用户验收和运行资源接入；所有处理帧都是候选版。
